# ทบทวน JavaScript — 12 บท

หน้าเว็บทบทวน JavaScript แบบ interactive (ภาษาไทย) ครอบคลุม 12 บท พร้อมแบบฝึกหัดและระบบเก็บคะแนน

**เปิดดูได้ที่:** https://phakinza007.github.io/js-review/

## รายละเอียด
- ไฟล์เดียวจบ (`index.html`) ไม่ต้องติดตั้งอะไรเพิ่ม
- ใช้ฟอนต์ IBM Plex Sans Thai / IBM Plex Mono จาก Google Fonts
- บันทึกความคืบหน้าไว้ใน localStorage ของเบราว์เซอร์
